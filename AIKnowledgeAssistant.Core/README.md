# AIKnowledgeAssistant.Core

Class library referenced by **Manual** and **SemanticKernel** console apps.

- `Data/InMemoryTaskStore` — task list and write operations  
- `Configuration/AiSettings` — Azure settings shape  
- `Tools/TaskToolNames` — shared tool names + `RequiresUserConfirmation`  
- `Services/AzureEndpointHelper` — endpoint normalization for both apps  

No OpenAI or Semantic Kernel packages here — only shared domain code.
